# Mẫu tài liệu game (mọi file `docs/games/*.md` theo thứ tự mục này)

1. **Mục đích**: kỹ năng IELTS phục vụ, dạng câu hoặc tiêu chí chấm liên quan, vì sao cần cho 8.0.
2. **Vì sao hiệu quả**: nguyên tắc học P1–P7 (`02` §1) áp dụng. Nêu rõ vì sao cơ chế chơi chính là hành động học.
3. **Core loop**: sơ đồ 1 lượt.
4. **Luật chơi**: chế độ, số lượt, thời gian, chấm điểm, XP, combo, khi nào kết thúc.
5. **Độ khó**: level 1–10 ảnh hưởng tới gì.
6. **Flow màn hình và wireframe**: ASCII, từng trạng thái.
7. **Feedback**: nội dung, câu thắng ở recap.
8. **SRS**: item nào tạo hoặc cập nhật, face nào, autoRate.
9. **Data**: file, schema (tham chiếu `04`), số lượng MVP/đầy đủ, cách sinh (tham chiếu `05`).
10. **UI, motion, sound riêng**: phần khác với chuẩn ở `08`/`10`.
11. **Edge cases**.
12. **Cổng nghiệm thu (đo được)**.
13. **Không làm**.
